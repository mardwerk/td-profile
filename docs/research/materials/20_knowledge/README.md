# Source review status

These labels describe dated research evidence, not product acceptance. A proposal remains unaccepted even when its supporting source is confirmed.

## Status labels

- Confirmed: primary source content was checked or the included example was reproduced on the stated review date.
- Metadata only: identity, title, authors, year or identifier were checked; the attributed content was not read.
- Unverified: the source or claim could not be checked; preserve the recorded reason.
- Contradicted: a checked source, another draft or a reproduced example disagrees; preserve both sides.

Use local source notes for the original inspection date, attribution, method and access limits. No new source review or runtime verification is implied by this collection.
