# Minimal game

This synthetic example uses the root `profile/` Template. It contains one Tower family with three states and two separate Upgrade definitions. Each state embeds an attack, weapon, projectile and damage model. The final state also has an ability that references its source upgrade.

Validate the example or score `Towers/Bolt/Bolt-0.json` with the commands in [the Profile Template](../../profile/README.md). The complete family earns 100 points for declared compliance. These values are synthetic and make no balance claim.
