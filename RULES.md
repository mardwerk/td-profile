# Repository rules

- Write documentation, issues and pull requests in English.
- Before establishing a term, search accessible repository glossaries for the term, aliases and the intended concept. Reuse the existing Accepted spelling and definition when the meaning matches. Ask Kyle before adopting a new or different meaning, resolving conflicting definitions or proceeding with incomplete search coverage. Record accepted terms in this repository's `GLOSSARY.md`.
- Keep local definitions complete. Other glossaries inform vocabulary review without governing this repository's behavior.
- When asked for open issues, exclude `status:out-of-scope` by default. Include it when explicitly asked for all open issues, out-of-scope proposals or parked proposals. Preserve other open states unless the request narrows them.
